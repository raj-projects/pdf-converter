# PDFLab - Quick Start Guide

## 5-Minute Setup

### 1. Extract & Install
\`\`\`bash
cd pdflab
npm install
\`\`\`

### 2. Start Development Server
\`\`\`bash
npm run dev
\`\`\`

### 3. Open in Browser
\`\`\`
http://localhost:3000
\`\`\`

Done! All 50+ tools are ready to use.

## Common Tasks

### Use a Tool
1. Click "Tools" in navigation
2. Select a tool from the grid
3. Upload PDF(s)
4. Configure options
5. Click process
6. Download result

### Add a New Tool
See [TOOLS_IMPLEMENTATION.md](./TOOLS_IMPLEMENTATION.md)

### Deploy to Production
\`\`\`bash
npm run build
vercel deploy
\`\`\`

### Deploy with Docker
\`\`\`bash
docker-compose up -d
\`\`\`
